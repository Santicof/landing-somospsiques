# Consultorio Integral Psique

Landing institucional desarrollada con React, TypeScript, Vite y Tailwind CSS.

## Desarrollo local

```bash
npm install
npm run dev
```

## Validaciones

```bash
npm run lint
npm run build
```

## Despliegue en Vercel

Vercel detecta automaticamente la configuracion de Vite:

- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

Los despliegues de produccion se generan desde la rama `main`.
